# pruebachatgpt

## Jugar al juego

Puedes abrir el archivo directamente en el navegador o levantar un servidor local.

### Abrir directamente

1. Abre `index.html` con tu navegador (doble clic o arrastrar el archivo a la ventana del navegador).

### Servidor local

```bash
python -m http.server 8000
```

Luego visita `http://127.0.0.1:8000/index.html` en tu navegador.

## Controles rápidos

- Mover la nave: WASD o flechas.
- Impulso extra: barra espaciadora.
- Atraer orbes cercanos: mantener pulsado clic o toque sobre el canvas.
